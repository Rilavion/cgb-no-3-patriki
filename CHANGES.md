# ЦГБ №3 — что изменено в этой версии

## Почему «не видно» служебных разделов (важно!)
Все перечисленные разделы на месте — они просто **скрыты системой прав**:
смотрит роль из таблицы `user_roles`. Полный доступ даёт роль `admin`.
После входа без роли видны только публичные страницы и часть заявок.
**Решение — один SQL-запрос** (см. SUPABASE-SETUP.md «Шаг 1.5»):
```sql
insert into public.user_roles (user_id, role, display_name)
values ('ТВОЙ-UUID-ИЗ-Authentication→Users', 'admin', 'Главный врач')
on conflict (user_id) do update set role = 'admin';
```
После этого в меню появятся все «Мои заявки» и всё «Служебное».

## Порядок запуска
1. Supabase → SQL Editor → выполнить `SUPABASE-SETUP.sql` (инструкция в `SUPABASE-SETUP.md`).
2. Залить всё содержимое папки в репозиторий на GitHub (GitHub Pages).
3. Свои `logo.png` и `fon.png` положить в корень (в архиве их нет специально).
4. Настроить и запустить бота по `bot/BOT-SETUP.md` (`npm install && npm start`).
